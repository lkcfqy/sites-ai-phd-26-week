### 独立本地启动

需要 Node.js 22.13+（AI 课程内存 SQLite 检查建议 Node.js 24）。先运行 `npm run install:ci`，按下文初始化本地数据库，然后运行 `npm run dev`（默认本地端口 5173）。生产构建为 `npm run build`，构建后本地预览为 `npm start`。开发登录为本地模拟身份，不是原 Site 的真实账户；不要把开发服务器作为安全的生产登录服务公开。

`.env.example` 仅说明配置入口，不含密钥。本项目当前不需要用户 API 密钥；`DB` 是 Cloudflare D1 绑定而非 `.env` 字符串。托管登录需要你自己的 Sites 平台环境。导出不会带入任何已有云端学习数据。

AI 课程首次本地数据库初始化可运行 `npm run db:migrate:local`。历史 `docs/`、`verification/`（含账户备份/截图）以及 Python runner 的历史执行回执已整体排除，避免携带用户/运行环境资料。源码检查脚本若依赖这些历史回执，需要自行生成新证据；不代表应用运行依赖缺失。`services/python-runner` 为可选历史参考实现，当前学习流程不调用；不得未经隔离与安全评估直接上线。

面向自学者的中文 AI 课程，主要导航为**学习**与**考查**。本仓库为独立源码导出，不含原 Site 的账号或历史记录。

26周建议路线由共同基础（1–6周）、机器学习与深度学习（7–12周）、三选一专项（13–16周）及研究材料/综合推理（17–26周）组成。全站170课，选择一个专项后主线130课。进度以理解与复测为依据，可以延长某周；课程完成不保证自动达到博士或独立研究水平。

每课的默认学习内容是完整自学主讲：现实问题、带核对答案的前置术语、分步解释、完整推演、可见中间结果表、减少提示的选择题例子和自检清单。重要几何、梯度、注意力、分割、时间依赖和校准概念配教学图示。原有概念、公式、代码与进一步推导放在可展开的补充材料中。算例表标明教学条件，不把手算或构造数字称为真实训练实测。学习者无需安装运行环境，也不需要保存、上传或提交代码、项目或报告。

## 考查与复习

- 每课3道基础题，需全部正确；新版深化5题，至少4题正确。深化题组独立使用`depth-v2`；此前`depth-v1`的最近/最高分及全部作答保留，单独展示历史，不冒充新版通过。
- 新版深化首次通过满7×24小时后，开放3道此前未下发的独立迁移变式，需全对通过。未通过先补弱，满24小时可重做同组；明确区分首次新题与补弱重做，保存首次、最近、最高分和次数。不把重复原题当作新的独立迁移证据。末周新课的一周复测在26周主线结束后继续完成。
- 原基础复习继续按原有间隔执行，深化延迟复测在“考查→错题与复习”中单独列出，课程内也可查看开放时间。
- 阶段考查保留现有6题与历史成绩；基础、深化、复测和阶段题各题选项的显示顺序使用稳定置换，提交的是选项在题库中的原索引，避免旧答案周期成为线索。解析使用具体选项含义，避免位置指代错配。
- 新增170道讲解内半完成例题，只用于阅读反馈，不写入正式考查成绩。全站正式课后题为510基础＋850新版深化＋510延迟迁移题；单条主线为390＋650＋390题。

账号通过ChatGPT登录。未提交的正式考查答案按账号保存在当前标签页；账号变化会阻止旧标签页继续读取/提交。服务器从版本化题库计分，不接受客户端分数。公开课程接口不包含延迟题组，延迟题接口要求登录、匹配账号上下文及服务端到期判断；首次提交后答案才随逐题反馈返回。

## 数据兼容与边界

无需新增或重置数据库表。深化和复测都使用既有`attempts`，分别用`depth:`/`retention:`课程键及独立版本。复测提交以本轮到期时间生成事件身份，避免同轮并发重复计次。旧代码、笔记、项目与研究数据不删除；完整认证导出仍保留历史原记录。原代码评测、AI辅导、研究提交及导入接口继续返回410。

这些考查反馈理论理解、计算、证据判断与间隔后的保持情况。真实编程、模型训练执行、原创研究和新场景部署能力需要相应实践证据；不由题目数量、单次最高分或自报学习时长认证。

## 开发与验证

使用Node.js 22.13+；内存SQLite回归脚本需要`node:sqlite`（本次环境Node24）。保留框架与依赖锁；本地使用独立数据库，部署时配置你自己的 Site ID 和绑定。

```sh
npm run install:ci
npm run typecheck
npm run check:learning
npm run check:depth
npm run check:self-study
npm run build
```

`check:learning`运行实际TypeScript路由与storage，使用真实迁移、内存SQLite和显式测试身份；不启动服务器、不联网、不读写真实学习者数据。覆盖旧流程退役、服务端评分、历史兼容、账号隔离、两类复习门限、首次/最新/最高分、题组版本及答案隐藏。

`check:depth`核对170课/850深化题，独立计算13项固定数值答案，并实际服务端渲染170份深入讲解、五题表单与170份自学主讲/半完成例，检查只读内容与教学图示。`check:self-study`检查全部170份自学结构、结果表、510道独立迁移题、覆盖/题目唯一性、延迟题不与已公开的考查或半例题干重复，以及显示置换的答案索引映射。篇幅检查仅防止空洞材料，不能替代数学或教学质量审查；各分区算例另行核对。
