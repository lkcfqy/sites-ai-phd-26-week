保存的 npm 审计为生产 0、开发 6 个依赖节点计数，对应 2 项 esbuild 公告；当前 Mac 调用路径与 Worker 产物未发现相应可达条件，见外部交接 `DEV_DEPENDENCY_EXPOSURE_ZH.md`。本轮未增加依赖、改 lock、强制大版本迁移或网络重审计，也没有 Python 漏洞审计结论。
