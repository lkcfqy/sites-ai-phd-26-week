## 先确认可隔离的目标

1. 用现有 Sites 能力确认是否能在相同身份代理和 D1 拓扑下建立仅所有者可见的独立预发布版本，绑定**独立测试 D1**。若只能覆盖生产站或共用生产库，停止并报告该平台限制，由父任务决定下一步。
2. 保持现有 AI owner-only。先使用所有者的两个隔离会话/设备验证本人跨设备行为；另一个未授权身份应被入口拒绝，不能为了测试悄悄扩展共享权限。只有平台原已允许且父任务批准两个写入测试身份时，才补真实跨账号写入隔离；否则明确保留为未验证，沿用本地合成身份隔离证据，交父任务判断。
3. 只用新建合成学习记录；不得读取/复制生产学习记录或 `.env` 内容。需要核对的名字是 D1 绑定 `DB`、已有 Sites 身份代理。可选历史 runner 的 `GRADER_URL` / `GRADER_TOKEN` 不属于本次必需能力，`CONNECTORS` 未配置。若平台需新凭据、权限或付费资源，先停止该步，不自行创建。
4. `hosting.json` 中 `YOUR_SITES_PROJECT_ID` 继续是占位符；实际目标由父任务核实配置流程后处理，不往公开仓库填生产配置。先固定待测源码摘要与回滚版本。

## 合成记录验收顺序

| 检查 | 通过证据 |
| --- | --- |
| 构建与入口 | QA 合成身份入口未进入部署；资源、CLI/评测源码、下载包和返回路径可用，快照匹配 |
| 登录/退出与信任边界 | 正常登录、退出、受控回跳、退出后返回/缓存；外部伪造 `oai-authenticated-user-*` 被真实代理清除或拒绝，不能只靠本地 mock 推断 |
| D1 schema 与旧记录 | 在测试库检查迁移、表、索引；用脱敏的格式夹具覆盖 v1 历史和新 v2，不 reset 生产库；验证重启后保留 |
| 草稿/CAS | 两个所有者会话先后编辑，旧版本被 409 拒绝；保留草稿重读；空 raw 的导入/评测文字、空 attemptId 的评阅文字均能比较；取消保持本地，确认采用才替换；再保存只写确认后的版本 |
| 尝试/评阅/重试 | 普通 debug、语法错误、超时、失败→自评→新尝试链；历史不可覆盖，旧 v1 可读，失败执行不会呈现通过 |
| 来源持续保留 | 八个仿真生成→导入→刷新→评阅/反思→备份往返保持 simulation；手改来源/删轨迹/改指标拒绝；不满足实机门槛。CPU 记录仍为提交的实测记录 |
| 失败保护 | 测试绑定缺失/错误、网络失败、过期版本；有可读反馈且输入可导出/保留；不向用户暴露秘密 |
| 设备与键盘 | 390 px 和桌面：函数/循环/with 缩进、复制文本、无横向页面溢出；八模型控件/完整轨迹；Tab/Shift+Tab/Escape、确认焦点、返回与未保存保护 |
| 恢复/回滚 | 仅在测试库演练备份、恢复及旧版本读取新记录；写入失败/不兼容时不损坏记录，保留证据和恢复步骤 |

每项保存版本、时间、合成账号代号、实际结果与失败材料；不保存会话令牌。无法验证的边界写成未验证，不用模拟通过替代。
