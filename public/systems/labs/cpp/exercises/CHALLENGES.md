# 独立修改与陌生任务验收

先复制整个目录。保留原参考和第一次结果，在副本中修改；输出新文件名。以下是公开练习契约，不是隐藏测试或岗位认证。

## A. 加权平均：从声明到链接

新增声明与定义 `weighted_mean(const std::vector<double>& values, const std::vector<double>& weights)`。

- `[10,20]`与`[1,3]` → 17.5；`[7]`与`[2]` → 7。
- 空输入、长度不同、负权重、权重全零：必须明确拒绝。
- 保证调用不改变输入；不要只更新固定结果。
- 在新输入 `[2,8,5]`与`[2,1,3]`上先手算，再测试。
- 交付：头文件、实现、测试、错误案例、可重跑命令。评审问题：为什么不按元素数量求平均？为什么要用double累加？

## B. 转置与所有权

实现 `Matrix transpose(const Matrix& input)`，返回新矩阵。

- 2×3输入`[[1,2,3],[4,5,6]]` → 3×2 `[[1,4],[2,5],[3,6]]`。
- 转置两次恢复原值；1×5、5×1、3×3均通过。
- 修改输出不改变输入，证明没有误返回原对象可变引用。
- 加入至少一个越界拒绝测试；解释对象生命周期和存储偏移。
- 迁移问题：如果只交换shape而没有重排数据，会在哪个例子失败？

## C. 并行点积

新增串行参考与线程局部归并的 `parallel_dot`。

- 两向量长度不同必须拒绝；空向量约定返回0或拒绝，并保持串/并一致。
- 长度0、1、7、101、1003；线程1、2、4、8；必须验证覆盖与不重叠。
- 使用能覆盖本实验范围的整数累加，明确防溢出的输入限制；浮点扩展单列误差规则。
- 计时是否包括线程创建、join？写清楚，不用预建池结果与串行包含初始化结果混比。
- 陌生变式：每个元素计算开销增加后，线程数选择是否改变？用证据而不是经验猜测。

## D. 矩形优化与公平边界

扩展到M×K乘K×N，在资源预算内至少覆盖(2,3,4)、(31,17,19)、(65,7,33)。

- 为转置B候选分别测包含预处理、预处理后重复复用；两个口径各自与公平基线比较。
- 用多个tile测试不整除边界与tile大于维度，不把越界当作有效优化。
- 保留不加速情况；报告所有样本与交替运行顺序。
- 用不在调参集合中的新shape复测；讲清最优tile为何不一定迁移。
- 禁止通过跳过元素、返回缓存旧答案或放宽误差阈值制造加速。

## E. 综合交接：陌生仓库式考核

请同伴或未来的自己在不看完整参考的情况下给出一个不同的矩阵/归并接口与失败输入。任务包括：

1. 复现构建，说明目录和依赖；
2. 写最小失败测试；
3. 定位一个逻辑/边界问题并最小修复；
4. 证明正常与异常输入仍正确；
5. 在固定预算内设计并执行性能对照；
6. 写PR风格说明、负结果、风险与回滚方式；
7. 解释一处自己没有验证的边界。

按正确性、可复现性、测量有效性、因果推理、维护性五维评审。每维需有具体文件/命令/数据，不以看过课、答对选择题或生成一份JSON代替。只有参考任务自测时标“自测”；没有独立评审就不要填写“已被第三方验证”。
